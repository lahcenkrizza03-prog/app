# upip-tv.com · upip-tv.com

Generated static website for Porkbun GitHub Connect.

Choose repository **app**, branch **porkbun**, in the Static Hosting settings for **upip-tv.com**. The website starts at index.html in this branch's root.

The maintained source is in [main](https://github.com/lahcenkrizza03-prog/app/tree/main). Build using npm run build:porkbun and verify using npm run test:porkbun. Source revision: 70cc36b.

Public informational pages are eligible for indexing. Unfinished legal pages retain noindex and are excluded from the sitemap.
